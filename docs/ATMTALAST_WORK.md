## Инструменты и проверки

- Python: `C:\Users\Pitynna\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`. Для скриптов выставлять `PYTHONUTF8=1`.
- Для записи исходников пользоваться атомарным `tmp/removal/io_utils.py`: временный соседний файл + replace. Прямая запись иногда возвращает Windows Errno 22.

- Bun: `tmp/bun/bun-windows-x64-baseline/bun.exe`; кэш `BUN_INSTALL_CACHE_DIR=tmp/bun-cache`. Сборка: `bun tools/build/build.ts --ci tgui`; типы: `bun run --cwd tgui tgui:tsc --noEmit`.
- `git apply --ignore-space-change` нужен для подготовленных LF-патчей к CRLF-файлам Windows. Перед применением делать `--check`.
- Для проверки всех карт генерировать `_maps/templates.dm` из `_maps/map_files/**/*.dmm` и `_maps/templates/**/*.dmm`, затем DM с `-DALL_MAPS -DCITESTING`. Генерируемый include удалить перед коммитом.
