# Ulthor: восстановление по скриншоту от 2 мая 2024

Источник: `Z:\ATMTA\ULTHOR\StrongDMM-2024-05-02_23.05.10.png` (6080×5600,
190×175 клеток). Клетка (0,0) скриншота — клетка карты (23,234).
Скриншот новее карты от 29 апреля (`Desktop\говно2\last\Ulthor.dmm`,
SHA-256 `daca1430…`), с которой делался перенос; в git её сконвертированная
версия — `061994c:_maps/map_files/Ulthor/Ulthor.dmm`.

Правило: берём с фото планировку и обстановку, наши функциональные правки
(зоны, АПЦ, тревоги, камеры, кабели) сохраняются. Новое помещение — своя зона,
свой АПЦ, пожарная и воздушная тревоги, камера, кабель одной трассой.

## Как работать

- `python tools/ulthor/photo_restore.py` — пересобирает карту из коммита
  `RESTORE_BASE` (541a0de) и применяет все участки из `REGIONS`. Повторный
  запуск безопасен. Новый участок — новая функция плюс запись в `REGIONS`.
- `python tools/ulthor/photo_lines.py` — распознаёт на фото кабели, подачу,
  вытяжку и трубы утилизации с направлениями → `tools/ulthor/photo_lines.json`.
  `M.photo_cables(box)` кладёт кабели по фото.
- Проверка: `python tools/ulthor/check_map.py`, сборка
  `dm.exe -DCBT -DCIBUILDING paradise.dme`.
- Розовые клетки на фото — насосы шлюзовых камер (у старой сборки не было спрайта),
  пурпурные квадраты на стенах — случайные постеры.
