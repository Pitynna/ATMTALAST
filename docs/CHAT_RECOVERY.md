# Восстановление чата и безопасный запуск

6 ноября 2026 при запуске локального сервера повторилось удаление файлов
проекта. `server_maint.Initialize()` и `Shutdown()` рекурсивно удаляли `tmp/`.
При наличии в нём junction-ссылок такая очистка могла затронуть исходники,
карты и ресурсы, на которые указывали ссылки. Отсутствующие JavaScript/CSS
приводили к пустому чату и ошибке `Failed to load fancy chat`.

Обе рекурсивные очистки удалены. Создатели временных файлов должны удалять
только собственные файлы. Правила из `AGENTS.md` запрещают junction/symlink
на каталоги проекта; проверочные скрипты в этом изменении их не создают.
Существующий игровой билд нужно пересобрать перед следующим запуском:
изменение исходников не исправляет уже скомпилированный сервер.

Дополнительно исправлены первый запуск чата с пустыми, несовместимыми или
повреждёнными настройками и повторная обработка очереди сообщений. Ранее
внесённое исправление восстановления чата сохраняет обычный вывод до
готовности интерфейса и не выводит ложную ошибку после успешной загрузки.

Проверки:

- `tools/ci/test_tgui_chat.py` проверяет собранный JavaScript в установленном
  Chrome: четыре состояния хранилища, очередь, русские сообщения, повторы,
  запрос пропущенного сообщения и открытие панели. При необходимости путь
  к браузеру задаётся переменной `CHROME_BINARY`.
- `code/tests/test_server_temp_cleanup.dm` проверяет сохранность вложенного
  файла в `tmp/` после инициализации и завершения `server_maint`.
- `python tools/ci/test_server_temp_cleanup.py` компилирует и запускает эту
  проверку на настоящем сервере. Каталоги проекта не копируются и не связываются
  ссылками; журнал и результат сохраняются в `docs/chat_repair/`.
- Обычная сборка: `E:\BYONDa220\bin\dm.exe -DCBT -DCIBUILDING paradise.dme`.

Сначала собирается TGUI штатной командой проекта, затем игровой сервер.
После пересборки сервер нужно перезапустить, чтобы обновился кэш ресурсов.

Для воспроизводимой сборки закреплён `sass-embedded` 1.107.1 и добавлен lockfile
TGUI. Проверенный npm-архив `sass-embedded-win32-x64` 1.108.0 не содержит
`sass.snapshot`; с ним сборка стилей завершалась ошибкой embedded compiler.

Проверено 6 ноября 2026: обычная сборка сервера и сборка целевого теста —
0 ошибок / 0 предупреждений; TGUI и шрифты собраны; TypeScript прошёл.
Браузер: четыре сценария по восемь проверок PASS. Runtime-тест сохранности
`tmp/` PASS. После его выполнения отсутствующих отслеживаемых файлов — 0,
reparse points в `tmp/` — 0. Ручная визуальная проверка в DreamSeeker не
выполнялась: инструмент управления окном недоступен.
