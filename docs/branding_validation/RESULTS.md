## Промежуточные результаты

Первая сборка выявила ошибку отступов у нового условия Wiki в ранее чрезмерно отступленной процедуре ревенанта. Отступы всей процедуры приведены к обычному уровню и сохранены коммитом dc69928.

Повторная сборка под обычным именем не завершилась: `paradise.rsc` заблокирован уже работающим DreamDaemon. Сообщения cannot find file при этом связаны с блокировкой ресурса; файлы существуют. Чтобы не останавливать чужой сервер, успешная финальная проверка выполнена с отдельным именем бинарника.

Итог после уточнения пользователя: блокирующий старый локальный сервер остановлен. Штатный `paradise.dme` пересобран в `paradise.dmb`: 0 ошибок / 0 предупреждений (`dm-main-build.log`). Временные файлы сборок из корня удалены по проверенному списку обычных игнорируемых файлов, без рекурсивной очистки. В корне остался единственный `.dmb` — `paradise.dmb`, с обязательным `paradise.rsc`. Сервер после сборки не запускался.
