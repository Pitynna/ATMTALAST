## Совместимость

Атмосфера снова использует восемь газов: кислород, азот, углекислый газ, плазму, закись азота, агент B, водород и водяной пар. Формат обмена DM/Rust: 22 значения для тайла, 26 для interesting tile. При изменении этого формата обязательно пересобирать Rust-библиотеки вместе с DM.

Интерфейс метаданных газов и методы газовых смесей сохранены для современных машин. Негазовый экспорт карго, обычный синдикатский контент, другие базы и независимые системы сохранены. Оружие удалённых семейств на картах заменено прежней лазерной винтовкой; специализированные предметы удалены.

Поставляемые Rust-библиотеки собираются для 32-разрядных Windows GNU и Linux GNU. Вариант Linux `_prod` также использует переносимую сборку без настройки под конкретный процессор.

## Проверки

Проверки выполняются по исходникам этой ветки: компиляция всех карт, сборка TGUI, TypeScript, Rust и проверки газовых смесей. Регрессионные тесты находятся в `code/tests/test_gas_mixture.dm` и `rust/src/milla/simulate.rs`.

Результаты локальной проверки 4 ноября 2026:

- Обычная сборка DM: 0 ошибок, 0 предупреждений.
- Компиляция всех 221 карт: 0 ошибок, 0 предупреждений.
- Сборка TGUI и проверка TypeScript: успешно.
- Пять тестов MILLA, включая все восемь газовых слотов и горение водорода: успешно.
- Прямой обмен BYOND 516.1682 с Windows DLL: восемь газов, длина тайла, очистка и создание окружения проверены.
- Загрузка `test_tiny` со штатной инициализацией и тестом газовой смеси: успешно, без runtime-ошибок. Две иконки предпросмотра карт перегенерированы.
- Windows и Linux Rust-библиотеки пересобраны; Linux-артефакты проверены сборкой, запуск на Linux не выполнялся.

Полный набор CI-тестов с MySQL не запускался.

Команды для обычной среды разработки:

```text
tools/build/build.bat --ci dm -DCIBUILDING -DCITESTING -DALL_MAPS
tools/build/build.bat --ci tgui
bun run --cwd tgui tgui:tsc --noEmit
cargo test --manifest-path rust/Cargo.toml --release --target i686-pc-windows-gnu milla:: -- --test-threads=1
```

Для Windows GNU нужен 32-разрядный MinGW с DWARF-исключениями. Полный запуск штатного набора тестов требует окружения CI, включая тестовую MySQL.
