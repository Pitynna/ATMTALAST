# Ulthor: обозначения зон в StrongDMM

Проверено 6 ноября 2026 года. В карте 109 областей. У 46 из них наследовался
`/area.icon_state = "unknown"`: редактор показывал кресты, хотя отдельные
области и их питание уже существовали. Пустых определений зон после правки нет.

## Изменения

- Для 46 существующих областей Ulthor заданы собственные `icon_state` из
  `icons/area/areas.dmi`: кухня, бар, ботаника, театр, часовня, медбей,
  инженерные помещения, командные кабинеты, ИИ, телекомы и шаттлы.
  Аркада, уборщицкая, фитнес, криосон и склад часовни больше не обозначены
  одинаковой зоной спальни; переработка получила обозначение утилизации.
- Шесть общих/неполных типов заменены дочерними типами только для Ulthor:
  загрузка ИИ, офис КМа, робототехника с научным проходом, западное управление
  солнечными панелями и две солнечные батареи. Замены затрагивают 778 клеток;
  набор клеток каждого контура остался тем же. Общие определения других карт
  не изменены.
- По составу оборудования уточнены два инженерных названия: комната с
  фабрикатором и пультом дронов — `Ulthor Drone Control`, помещение с зоной
  отдыха и мониторами — `Ulthor Engineering Lounge and Monitoring`.

## Границы и проверки

Сопоставлены геометрия помещений, двери, оборудование и расположение АПЦ.
В баре и ботанике существующая разметка уже охватывала их помещения; новые
пустые контуры вместо неё не создавались. Поклеточное сравнение всей карты
подтвердило сохранение каждого объекта, его переменных, турфа и геометрии.
Менялись только обозначения и шесть типов областей один к одному.

- 109 областей, `unknown`: **46 → 0**. Все обозначения существуют в DMI.
- Статический аудит: **65 025 клеток, 98 АПЦ, 55 стартов, 90 камер,
  64 дверных пульта, 0 нарушений**.
- `dm.exe -DCBT -DCIBUILDING paradise.dme`: **0 ошибок / 0 предупреждений**.
- `dm.exe -DCBT -DCIBUILDING ulthor_mapcheck.test.dme`, включающий саму
  `Ulthor.dmm`: **0 ошибок / 0 предупреждений**.
- StrongDMM 2.18.0.alpha: открыты **paradise.dme и Ulthor.dmm**;
  журнал содержит `map opened`, заголовок — `paradise.dme [Ulthor.dmm]`.
  `Parser Error` и `Unknown Types` отсутствуют.
- Сервер в этой задаче не запускался. Контуры питания проверены статически;
  новый игровой прогон питания/атмосферы не выполнялся.
